# Experiment 023 — verdict

**Verdict: reject activity model fitting.**

The accepted direct-observation ledger contains 29 paid-attraction cities, only 3 half-day group-activity
cities, and 2 full-day premium-activity cities. Only Vancouver contains all three activity anchors. None of
the material model relationships can meet the frozen 30-city/10-holdout gate, so no activity ratio or
imputation is fitted. `activities_free = 0` remains definitional. Search feasibility remains separately
documented in Experiment 020; this audit does not claim that the Luna prompt can retrieve the observations.
